# Guide for coaches: from the match to training and back

Use this after a match. It takes about a minute and it is always skippable.

## 1. After the match: what do we work on this week?

1. Open the match and choose **Log result**.
2. Rate each phase of play out of 5.
3. In **What do we work on this week?**, the phase you rated lowest is already chosen. Change it if you disagree, then type the problem in your own words (for example, "We lose the ball when we play out from the back").
4. Save. A team can have **two** open focus areas at a time.

## 2. During the week: plan for it

Your coach home and the week plan show **This week** with each open focus. Tap **Plan a session** and the session builder opens with the problem already filled in. When you save the session, it is counted against that focus.

## 3. At the next match: did we see it again?

When you log the next result, you are asked about each focus from an earlier match: **No, it's gone**, **A bit** or **Yes, still there**. Your answer closes it with a verdict (improved, partly, not yet). If it is still there, tap **Keep working on it this week** to start a new one with the same words.

## 4. Look back

**Squad Review** lists **What we worked on**: each closed focus, its verdict, how many sessions were planned and how the phase rating moved between the two matches.

## What families see

Only parents and players with an approved weekly note see anything, and only one line about the whole team, such as "This week the team worked on keeping and using the ball." It names the phase of play, never a child, and never your own words. The line appears only for a focus that has a session planned. You read and can edit every note before it is shared.

## Good to know

- Only coaches see the focus areas. Parents and players cannot open them.
- Nothing here shows until the database update (migration 067) has been run.
- Nothing in this flow uses AI.
